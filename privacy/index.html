Privacy Policy

Last updated: 31 October 2026 · App: com.silentwater.fishing

This policy describes how data is processed in Silent Water and when you contact game support. For privacy questions, contact the developer at silentwater.support@gmail.com.

The main game works offline and requires no registration. Local network multiplayer is enabled separately by the user. The current version has no ads, real-money purchases or built-in developer analytics.

1. Data on your device

The game stores progress, settings, inventory, catches, quests, records and game world state in the app's local storage. Network play creates a random player identifier and saves your chosen or automatically generated nickname. This identifier is not an advertising ID, phone number or IMEI.

The developer does not automatically receive a copy of your offline saves. The current version has no dedicated cloud save service.

2. Local network multiplayer

After you start a search or create a session, the game exchanges data with devices on the network. Device network addresses are used for session discovery and connection. The session name, host nickname and session details may be visible to other users searching on that network.

Multiplayer fishing exchanges the following between participants:

• nicknames, random player identifiers and session identifiers;

• records, catch events, fish species and weights, and the selected game location;

• tackle state, equipped rigs and bait, necessary game supplies, wear, bonuses and groundbait information used to calculate fishing;

• shared game world, time and weather data, synchronisation messages and acknowledgements of game actions.

This data is used to connect, synchronise and restore network sessions, and display participants, catches and records. A player's device acts as the host, rather than a developer-operated server. Some session and transaction information may be stored on participants' devices for recovery and consistent accounting of results.

The absence of a central server does not mean that no data is transferred: other participants receive information needed for the selected network mode. Do not include your real name, contact details or other information you do not want to disclose in your nickname.

3. Security

Local data is kept in app storage whose access is restricted by the operating system. Network mode is intended for a trusted local network. Game messages between client and host are protected by DTLS. Before joining a running session for the first time, compare the certificate code on both devices and confirm that it matches. Automatic reconnection verifies the same certificate; there is no fallback to unencrypted transport.

Session discovery and retrieval of the public certificate are unencrypted on the local network. Discovery may reveal the host nickname, device address, session and host identifiers, game version, participant count and whether a password is required. The private key, password and game saves are not transferred through discovery. Do not approve a code that does not match your friend's screen.

The host may set a session password. The password is sent only within DTLS and is not written to game saves. A separate certificate key is generated for each session launch and remains in the host's memory. Temporary recovery tokens and certificate trust are held in app memory. Encryption does not hide game data from the host or its intended participants and does not protect a compromised device. Do not use network mode to transmit confidential information.

4. Support and bug reports

If you email silentwater.support@gmail.com, the developer receives your sender address, message and attachments. Saves, screenshots and diagnostic files may contain player identifiers, nicknames, progress and technical information. Send only the data needed to resolve your issue. Do not send passwords, signing keys, payment details or identity documents.

Correspondence is used to reply, resolve bugs and process data requests. Support enquiries are handled through Gmail; Google processes email under its own terms and privacy policy.

5. Third parties and external services

The developer does not sell player data or use it for advertising profiling. The current game version has no embedded developer advertising or analytics SDKs. Transfers to other players in network mode are described above.

Distribution through Google Play is governed by Google's rules and policies. Google may process installation and store-operation information independently of the game developer.

This page is hosted on GitHub Pages. It contains no analytics trackers of ours, external fonts or advertising scripts. When you visit the site, GitHub may process technical information, including your IP address, under GitHub's privacy policy.

6. Retention and deletion

Local saves and network-mode data remain until deleted or replaced by the app. You can clear them in Android settings: Apps → Silent Water → Storage → Clear data. Menu names vary by device. This deletes local progress; any separate copies you previously made must be deleted separately.

Deleting data on your device does not automatically delete records or copies on other participants' devices. The developer does not control their storage. Disconnecting from a session alone does not guarantee deletion of previously transferred information.

Support correspondence is retained for as long as needed to handle the enquiry, provide follow-up support and meet applicable legal obligations. Contact the support address to request deletion or information about data associated with an enquiry. The developer cannot remotely restore or delete your local save. The current game version has no user account registration.

7. Changes and enquiries

When game features change, this policy is updated on this page with a revised date. Material changes to data processing require appropriate notice to users; publishing this text does not replace consent where consent is required.

Questions and requests: silentwater.support@gmail.com.

Політика конфіденційності

Дата редакції: 31 жовтня 2026 року · Застосунок: com.silentwater.fishing

Ця політика описує обробку даних у грі «Тиха вода» та під час звернення до служби підтримки гри. З питань конфіденційності звертайтеся до розробника: silentwater.support@gmail.com.

Основна гра працює офлайн і не потребує реєстрації. Спільну гру в локальній мережі користувач вмикає окремо. У поточній версії немає реклами, покупок за справжні гроші та вбудованої аналітики розробника.

1. Дані на вашому пристрої

Гра зберігає прогрес, налаштування, інвентар, улови, завдання, рекорди та стан ігрового світу в локальному сховищі застосунку. Для мережевої гри створюється випадковий ігровий ідентифікатор і зберігається вибраний або автоматично створений нік. Цей ідентифікатор не є рекламним ідентифікатором, номером телефону або IMEI.

Розробник не отримує автоматичної копії ваших офлайн-збережень. У поточній версії гра не має власного хмарного сервісу збережень.

2. Спільна гра в локальній мережі

Після запуску пошуку або створення сесії гра обмінюється даними з пристроями в мережі. Для виявлення сесії та з'єднання використовуються мережеві адреси пристроїв. Назва сесії, нік ведучого та відомості про сесію можуть бути доступні іншим користувачам, які виконують пошук у цій мережі.

Для спільної риболовлі між учасниками передаються:

• ніки, випадкові ігрові ідентифікатори та ідентифікатори сесії;

• рекорди, події улову, види та вага риб, вибрана ігрова локація;

• стан снастей, використана оснастка та наживка, необхідні ігрові запаси, знос, бонуси й відомості про підгодовування для розрахунку риболовлі;

• дані спільного ігрового світу, часу й погоди, повідомлення синхронізації та підтвердження ігрових дій.

Ці дані використовуються для з'єднання, синхронізації та відновлення мережевої сесії, відображення учасників, уловів і рекордів. Ведучим є пристрій одного з гравців, а не сервер розробника. Частина відомостей сесії та операцій може зберігатися на пристроях учасників для відновлення й узгодженого обліку результатів.

Відсутність центрального сервера не означає відсутності передачі даних: інші учасники отримують відомості, необхідні для вибраного мережевого режиму. Не вказуйте в ніку справжнє ім'я, контакти або іншу інформацію, яку не хочете розкривати учасникам.

3. Безпека

Локальні дані зберігаються у сховищі застосунку, доступ до якого обмежується засобами операційної системи. Мережевий режим призначений для довіреної локальної мережі. Ігрові повідомлення між клієнтом і ведучим захищені DTLS. Перед першим входом у запущену сесію потрібно порівняти код сертифіката на обох пристроях і підтвердити збіг. Під час автоматичного відновлення зв'язку перевіряється той самий сертифікат; переходу на відкритий транспорт немає.

Пошук сесій та отримання публічного сертифіката виконуються без шифрування в локальній мережі. Під час пошуку можуть бути видимі нік ведучого, адреса пристрою, ідентифікатори сесії та ведучого, версія гри, кількість учасників і наявність пароля. Секретний ключ, пароль та ігрові збереження через пошук не передаються. Не підтверджуйте код, який не збігається з кодом на екрані друга.

Ведучий може встановити пароль сесії. Пароль передається лише всередині DTLS і не записується в ігрові збереження. Ключ сертифіката створюється окремо для кожного запуску сесії та залишається в пам'яті ведучого. Тимчасові токени відновлення й довіра до сертифіката зберігаються в пам'яті застосунку. Шифрування не приховує ігрові дані від самого ведучого або учасників, яким вони призначені, і не захищає зламаний пристрій. Не використовуйте мережевий режим для передачі секретних даних.

4. Підтримка та повідомлення про помилки

Якщо ви пишете на silentwater.support@gmail.com, розробник отримує вашу адресу відправника, зміст листа та додані матеріали. Збереження, знімки екрана й діагностичні файли можуть містити ігрові ідентифікатори, ніки, прогрес і технічні відомості. Надсилайте лише дані, необхідні для вирішення питання. Не надсилайте паролі, ключі підпису, платіжні реквізити або документи, що посвідчують особу.

Листування використовується для відповіді, виправлення помилок та обробки запитів щодо даних. Звернення обробляються через Gmail; Google обробляє пошту відповідно до власних умов і політики конфіденційності.

5. Передача третім особам і зовнішні сервіси

Розробник не продає дані гравців і не використовує їх для рекламного профілювання. У поточній версії гри немає вбудованих рекламних або аналітичних SDK розробника. Передачу іншим гравцям у мережевому режимі описано вище.

Поширення через Google Play регулюється правилами й політиками Google. Google може обробляти відомості про встановлення та роботу свого магазину незалежно від розробника гри.

6. Строки зберігання та видалення

Локальні збереження та дані мережевого режиму зберігаються до видалення або заміни застосунком. Їх можна очистити в налаштуваннях Android: «Застосунки → Тиха вода → Сховище → Очистити дані». Назви пунктів залежать від пристрою. Це видаляє локальний прогрес; окремі копії, які ви зберегли раніше, видаляються окремо.

Видалення даних на вашому пристрої не видаляє автоматично записи й копії на пристроях інших учасників. Розробник не керує їхніми сховищами. Саме відключення від сесії не гарантує видалення раніше переданих відомостей.

Листування з підтримкою зберігається протягом часу, необхідного для обробки звернення, подальшої підтримки й виконання застосовних правових зобов'язань. Запросити видалення або отримати інформацію про пов'язані зі зверненням дані можна за адресою підтримки. Розробник не може дистанційно відновити або видалити ваше локальне збереження. У поточній версії гри немає реєстрації користувацьких облікових записів.

Политика конфиденциальности

Дата редакции: 31 октября 2026 года · Приложение: com.silentwater.fishing

Эта политика описывает обработку данных в игре «Тихая вода» и при обращении в поддержку игры. По вопросам конфиденциальности свяжитесь с разработчиком: silentwater.support@gmail.com.

Основная игра работает офлайн и не требует регистрации. Совместная игра в локальной сети включается пользователем отдельно. В текущей версии нет рекламы, покупок за реальные деньги и встроенной аналитики разработчика.

1. Данные на вашем устройстве

Игра сохраняет прогресс, настройки, инвентарь, уловы, задания, рекорды и состояние игрового мира в локальном хранилище приложения. Для сетевой игры создаётся случайный игровой идентификатор и сохраняется выбранный или автоматически созданный ник. Идентификатор не является рекламным идентификатором, номером телефона или IMEI.

Разработчик не получает автоматическую копию ваших офлайн-сохранений. В текущей версии собственного облачного сервиса сохранений у игры нет.

2. Совместная игра в локальной сети

После запуска поиска или создания сессии игра обменивается данными с устройствами в сети. Для обнаружения сессии и соединения используются сетевые адреса устройств. Название сессии, ник ведущего и сведения о сессии могут быть доступны другим пользователям, которые выполняют поиск в этой сети.

Для работы совместной рыбалки между участниками передаются:

• ники, случайные игровые идентификаторы и идентификаторы сессии;

• рекорды, события улова, виды и вес рыб, выбранная игровая локация;

• состояние снастей, используемая оснастка и наживка, необходимые игровые запасы, износ, бонусы и сведения о прикормке для расчёта рыбалки;

• данные общего игрового мира, времени и погоды, сообщения синхронизации и подтверждения игровых действий.

Эти данные используются для соединения, синхронизации и восстановления сетевой сессии, отображения участников, уловов и рекордов. Ведущим является устройство одного из игроков, а не сервер разработчика. Часть сведений сессии и операций может сохраняться на устройствах участников для восстановления и согласованного учёта результатов.

Отсутствие центрального сервера не означает отсутствия передачи данных: другие участники получают сведения, необходимые для выбранного сетевого режима. Не указывайте в нике настоящее имя, контакты или другую информацию, которую не хотите раскрывать участникам.

3. Безопасность

Локальные данные хранятся в хранилище приложения, доступ к которому ограничивается средствами операционной системы. Сетевой режим предназначен для доверенной локальной сети. Игровые сообщения между клиентом и ведущим защищены DTLS. Перед первым входом в запущенную сессию нужно сравнить код сертификата на обоих устройствах и подтвердить его совпадение. При автоматическом восстановлении связи проверяется тот же сертификат; перехода на открытый транспорт нет.

Поиск сессий и получение публичного сертификата выполняются без шифрования в локальной сети. При поиске могут быть видны ник ведущего, адрес устройства, идентификаторы сессии и ведущего, версия игры, число участников и наличие пароля. Секретный ключ, пароль и игровые сохранения через поиск не передаются. Не подтверждайте код, который не совпадает с экраном друга.

Ведущий может задать пароль сессии. Пароль передаётся только внутри DTLS и не записывается в игровые сохранения. Ключ сертификата создаётся отдельно для каждого запуска сессии и остаётся в памяти ведущего. Временные токены восстановления и доверие к сертификату хранятся в памяти приложения. Шифрование не скрывает игровые данные от самого ведущего или участников, которым они предназначены, и не защищает взломанное устройство. Не используйте сетевой режим для передачи секретных данных.
